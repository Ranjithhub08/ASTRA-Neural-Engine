## ⚡ Core Capabilities

*   **🧬 Neural PDF Decomposition**: High-fidelity client-side extraction using custom structural anchoring.
*   **🛠️ Tech-Stack Deep Dive**: Automatically identifies Methodology, Entropy Loss functions, and Neural Architectures.
*   **🎯 Zero-Hallucination QnA**: Answering engine restricted strictly to provided literature.
*   **🔮 Automated Synthesis**: Instant generation of Research Gaps, Agreements, and Contradictions.
